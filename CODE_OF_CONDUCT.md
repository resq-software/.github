# Code of Conduct

ResQ Software adopts the [**Contributor Covenant v2.1**](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as the Code of Conduct for every repository under the [`resq-software`](https://github.com/resq-software) organization.

Read the canonical text at the link above — it applies here without modification.

## Scope

This Code applies to all organization spaces: issues, pull requests, discussions, commit messages, code reviews, security advisories, and any public communication where you're representing the project.

## Reporting

If you observe or experience conduct that violates this Code, report it privately:

- **Preferred**: open a [GitHub Security Advisory](https://github.com/resq-software/.github/security/advisories/new) on this `.github` repo — advisories are private by default and route straight to maintainers.
- **Alternative**: email `conduct@resq.software`.

All reports are reviewed by the maintainers listed in [`.github/CODEOWNERS`](./CODEOWNERS) and handled confidentially. The reporter's identity is not shared beyond those directly involved in the review.

## Enforcement

Consequences follow the guideline ladder in Contributor Covenant v2.1 §4 (Correction → Warning → Temporary Ban → Permanent Ban). The maintainers' decision is final. Maintainers who violate the Code are held to the same standard.
